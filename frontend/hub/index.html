Local Hosting Architecture & Credentials

🔗 Unified Single-Port Serving

All 5 independent SPAs are served via server.mjs on http://localhost:3000. Relative asset paths (./shared/...) and hash routing are automatically resolved.

🔐 Authentication & Accounts

Each portal enforces strict role validation. When you sign in with an account, the backend validates the user's role and grants portal access accordingly.

🌐 Production Deployment

Each subfolder (student/, super-admin/, etc.) is ready for direct deployment to Cloudflare Pages with bundled security headers.
